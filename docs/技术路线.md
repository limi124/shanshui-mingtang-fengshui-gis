# 技术路线

MVP 采用 Vue 3 + OpenLayers 完成二维电子围栏绘制，FastAPI 接收 GeoJSON 后计算围栏面积、mock 地形指标、规则评分，并生成中文环境格局报告。

后续路线：

1. 接入真实 DEM GeoTIFF，完善裁剪、坡度、坡向、粗糙度、起伏度和方向剖面分析。
2. 接入水系、道路、建筑物、植被等矢量数据，计算水体距离、道路干扰、可达性和遮挡。
3. 接入 Cesium 地形、3D Tiles、倾斜摄影，形成三维地形观察与剖面分析。
4. 接入 PostGIS 作为空间数据管理底座。
5. 接入大语言模型时只传结构化分析结果，避免上传敏感位置坐标。
